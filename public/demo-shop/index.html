Bu səhifə necə qoşulub?

Mağaza OmniDLV-yə sifarişi API ilə göndərir və cavabda tracking_code alır. Müştəri səhifəsi isə açar tələb etməyən bir sorğu ilə statusu oxuyur:

GET /api/tracking?code=OD7KQ2MXR4PA9C
GET /api/tracking?order=NM-10409&phone=5590

fetch(OMNIDLV + '/api/tracking?code=' + code)
  .then(r => r.json())
  .then(t => t.status.category) // created | pool | assigned | in_progress
                                //  | on_delivery | completed | cancelled | failed

Ad və telefon maskalı gəlir; kuryerin yeri yalnız sifariş yolda olanda göstərilir.
